### Рекомендации для скриншотов:

1. **Реальные данные:** Используйте настоящие названия кофе, цены, фото
2. **Читаемость:** Текст должен быть чётким, не размытым
3. **Брендинг:** Если возможно, добавьте логотип Brewly в приложение
4. **Качество:** Скриншоты с Retina-дисплея (2x или 3x)

### Рекомендации для видео:

1. **Сценарий:** Покажите весь путь клиента — от открытия до получения заказа
2. **Звук:** Можно без звука или с фоновой музыкой
3. **Субтитры:** Добавьте текстовые пояснения ключевых моментов
4. **Динамика:** Не больше 2 минут, держите темп
