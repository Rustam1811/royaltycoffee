# Модернизация страницы управления заказами

## 🎨 Минималистичный современный дизайн

### Философия дизайна
- **Без эмодзи** - только текст и иконки Heroicons
- **Без градиентов** - чистые однотонные цвета
- **Минимум теней** - легкая тень только при hover
- **Строгая типографика** - четкая иерархия размеров
- **Больше белого пространства** - воздух между элементами

### 1. ✅ Локализация позиций заказа

Создан модуль утилит `admin/src/utils/orderLocalization.ts` с функциями для перевода:

- **Молоко**: `coconut` → Кокосовое молоко
- **Сиропы**: `chocolate` → Шоколадный сироп, `vanilla` → Ванильный сироп
- **Размеры**: `m` → Средний (M), `l` → Большой (L)
- **Температура**: `hot` → Горячий, `iced` → Со льдом

Функция `formatOrderItemModifiers()` собирает все модификаторы через разделитель " • ".

### 2. 🎨 Минималистичный дизайн

#### Цветовая палитра
```css
Фон приложения: bg-slate-50
Карточки: bg-white с border-slate-200
Акцентный: bg-slate-900 (кнопки, активные элементы)
Текст: text-slate-900 (основной), text-slate-500 (вторичный)
```

#### Статусы
- **Новый**: amber-50 / amber-700
- **В работе**: blue-50 / blue-700  
- **Готов**: green-50 / green-700
- **Выдан**: slate-50 / slate-600

#### Карточки заказов
```
- Фон: белый
- Рамка: 1px slate-200
- Скругление: rounded-lg (8px)
- Hover: тень + border-slate-300
- Padding: 24px (p-6)
```

#### Типографика
```
Заголовок страницы: text-3xl font-semibold
Номер заказа: text-xl font-semibold  
Секции: text-xs uppercase tracking-wider
Позиции: font-medium / text-sm
Цена итого: text-2xl font-bold
```

### 5. 🧹 Чистый код

**Архитектура:**
- Утилиты локализации вынесены отдельно
- Строгая типизация TypeScript (без any)
- Чистые функции без побочных эффектов
- Семантичные имена переменных

**Типизация:**
```typescript
interface OrderItem {
  name: string;
  quantity: number;
  price: number;
  sizeKey?: string;
  milkKey?: string;
  syrupKey?: string;
  temperatureKey?: string;
  intensityKey?: string;
}
```

**Responsive:**
- Mobile: 1 колонка
- Desktop (lg): 2 колонки
- Wide (xl): 3 колонки

### 6. 🎯 UX улучшения

- **Scroll для длинных списков**: max-h-80 overflow-y-auto
- **Четкая визуальная иерархия**: разделители border-b между секциями
- **Читаемые модификаторы**: на отдельной строке мелким текстом
- **Мгновенный фидбек**: whileTap для кнопок
- **Accessibility**: semantic HTML, proper contrast ratios
