## 🔧 Технические детали

### Клиентский QR-код

**Генерация:**
```typescript
const qrUrl = `https://api.qrserver.com/v1/create-qr-code/
  ?size=280x280
  &data=${encodeURIComponent(userId)}
  &bgcolor=000000
  &color=ffffff`;
```

**Формат данных:** Простой текстовый `userId` (например: `user_salvator_846`)

### QR-сканер (Admin)

**Библиотека:**
```bash
npm install html5-qrcode
```

**Конфигурация:**
```typescript
{
  fps: 10,                          // 10 кадров/сек
  qrbox: { width: 250, height: 250 }, // Область сканирования
  aspectRatio: 1.0,
  facingMode: 'environment'         // Задняя камера
}
```

**Автоматическое закрытие:** Камера закрывается сразу после успешного сканирования

### API интеграция

**Последовательность запросов:**
```typescript
// 1. Сканируем QR → получаем userId
const userId = decodeQRCode(imageData);

// 2. Загружаем данные пользователя
const response = await fetch(`/api/bonus?userId=${userId}`);
const data = await response.json();

// 3. Отображаем в интерфейсе
setCustomerBonus(data.balance);
setCustomerName(data.name);
setCustomerLinked(true);
```
