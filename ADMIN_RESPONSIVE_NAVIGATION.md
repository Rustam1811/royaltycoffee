# Обновление админ-панели: Респонсивная навигация с сайдбаром

## Обзор изменений

Админ-панель была полностью переработана для обеспечения лучшего пользовательского опыта на разных устройствах. Основные изменения:

### 🖥️ **Десктопная версия**
- **Сайдбар слева**: Постоянно видимая навигация на экранах шире 768px
- **Фиксированная ширина**: 256px (16rem) для стабильного расположения
- **Информация о пользователе**: Роль, ID и статус отображаются в шапке сайдбара
- **Активные индикаторы**: Синие акценты и точки для текущей страницы

### 📱 **Мобильная версия**
- **Скрытая навигация**: Сайдбар полностью скрыт по умолчанию
- **Кнопка-гамбургер**: Фиксированная кнопка в левом верхнем углу
- **Слайд-меню**: Сайдбар выезжает слева с плавной анимацией
- **Темный оверлей**: Затемнение фона при открытом меню
- **Автозакрытие**: Меню автоматически закрывается при выборе пункта

## Технические особенности

### 🎨 **Дизайн и стили**
```css
/* Ключевые классы Tailwind */
.sidebar-desktop: "hidden md:flex h-screen w-64 bg-white border-r"
.sidebar-mobile: "fixed left-0 top-0 h-full w-80 bg-white z-50"
.hamburger-button: "md:hidden fixed top-4 left-4 z-50"
.content-spacer: "hidden md:block w-64" /* Отступ для desktop контента */
```

### ⚡ **Анимации**
```tsx
// Анимации сайдбара
initial: { x: '-100%' }
animate: { x: 0 }
exit: { x: '-100%' }
transition: { type: 'spring', damping: 25, stiffness: 200 }

// Анимации переключения страниц
variants: {
  initial: { opacity: 0, y: 20 },
  in: { opacity: 1, y: 0 },
  out: { opacity: 0, y: -20 }
}
```

### 📱 **Responsive breakpoints**
- **Mobile**: < 768px (md breakpoint)
- **Desktop**: ≥ 768px
- **Автоматическое переключение** через `window.innerWidth`

## Использование

### Для разработчиков
```tsx
// Использование компонента
import ResponsiveAdminNavigation from './components/ResponsiveAdminNavigation';

<ResponsiveAdminNavigation 
  currentRoute={currentRoute}
  onRouteChange={setCurrentRoute}
/>
```

### Для пользователей
1. **Desktop**: Используйте сайдбар слева для навигации
2. **Mobile**: Нажмите кнопку ☰ в левом верхнем углу
3. **Выбор страницы**: Кликните на нужный пункт меню
4. **Закрытие на mobile**: Кликните на оверлей или выберите пункт
