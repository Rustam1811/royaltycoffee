# 📱 Full-Screen Sheet - Чеклист для тестирования

## Что проверить после деплоя

### ✅ Основная функциональность

- [ ] **Открытие шторки**
  - Нажми на любой продукт в меню
  - Шторка должна **плавно выехать снизу на весь экран**
  - Анимация spring (bounce эффект)

- [ ] **Закрытие свайпом**
  - Потяни шторку вниз пальцем
  - Если протянешь > 20% экрана - закроется
  - Если меньше - вернется назад (spring bounce)

- [ ] **Быстрый свайп**
  - Резко свайпни вниз (быстрое движение)
  - Должна закрыться даже если протянул < 20%

- [ ] **Кнопка закрытия**
  - В header справа есть кнопка ×
  - При клике - плавно закрывается

### ✅ Визуальные элементы

- [ ] **Drag handle** (палка сверху)
  - Видна серая полоска 12×6px вверху
  - При драге курсор меняется на grabbing

- [ ] **Header**
  - Слева: название продукта (bold)
  - Справа: кнопка закрытия (круглая)
  - Sticky (прилипает при скролле)

- [ ] **Full-screen**
  - Занимает 100% высоты экрана
  - Нет скруглений снизу
  - Выглядит как нативная шторка iOS

### ✅ Скролл и интерактивность

- [ ] **Скролл контента**
  - Листай контент внутри шторки
  - Не должно конфликтовать с драгом

- [ ] **Выбор опций**
  - Тапай на размеры (S/M/L)
  - Выбирай молоко, сиропы
  - Всё должно откликаться быстро

- [ ] **Количество**
  - Кнопки - / + работают
  - Цена пересчитывается

- [ ] **Кнопка "Добавить"**
  - Sticky внизу (z-120)
  - Не перекрывается шторкой
  - При клике - flying animation к корзине

### ✅ Edge Cases

- [ ] **Быстрое открытие/закрытие**
  - Открой и сразу закрой
  - Не должно глючить

- [ ] **Scroll + Drag**
  - Скролль контента наверх
  - Попробуй драгнуть шторку
  - Должно работать корректно

- [ ] **Landscape режим**
  - Поверни телефон
  - Шторка должна адаптироваться

- [ ] **iOS home indicator**
  - На iPhone с home indicator
  - Кнопка "Добавить" не должна перекрываться

### ✅ Performance

- [ ] **60 FPS анимации**
  - Откройте Chrome DevTools
  - Performance tab
  - Проверьте FPS при драге

- [ ] **No layout shifts**
  - При открытии шторки
  - Страница не должна "прыгать"

- [ ] **Smooth spring**
  - Анимация должна быть упругой (bounce)
  - Не резкой, не медленной

## 🐛 Если что-то не работает

### Шторка не открывается
1. Проверь консоль на ошибки
2. Проверь что `openId` устанавливается
3. Проверь `AnimatePresence` работает

### Свайп не закрывает
1. Проверь threshold: `info.offset.y > height * 0.2`
2. Проверь velocity: `info.velocity.y > 500`
3. Проверь `drag="y"` установлен

### Лагает анимация
1. Проверь `will-change-transform`
2. Проверь `transform-gpu`
3. Reduce motion если включен

### Скролл конфликтует
1. Проверь `touchAction: 'pan-y'`
2. Проверь `dragDirectionLock`
3. Проверь `overscroll-contain`
