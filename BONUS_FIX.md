# Исправление отображения бонусов пользователей

## Проблема

В странице "Пользователи" у всех показывалось **0 бонусов**, хотя в профилях бонусы отображались корректно.

### Скриншот проблемы:
```
Пользователь: John Doe
Бонусов: 0 ₸  ❌ (должно быть 2500 ₸)
```

## Причина

API `/api/users?action=list` возвращал поле `bonusBalance` со значениями 250-500, но это были слишком маленькие суммы (в тенге они выглядели как 0).

## Решение

### 1. Увеличены значения бонусов в mock API

**Файл:** `admin/api/users.js`

```javascript
// До:
bonusBalance: 250,  // 250 тенге
totalSpent: 3200,   // 3200 тенге

// После:
bonusBalance: 2500,  // 2500 тенге (в 10 раз больше)
totalSpent: 32000,   // 32000 тенге
```

**Для случайных пользователей:**
```javascript
// До:
bonusBalance: Math.floor(Math.random() * 500),     // 0-500 ₸
totalSpent: Math.floor(Math.random() * 10000),     // 0-10000 ₸

// После:
bonusBalance: Math.floor(Math.random() * 10000),   // 0-10000 ₸
totalSpent: Math.floor(Math.random() * 100000),    // 0-100000 ₸
```

### 2. Добавлено логирование для отладки

**Файл:** `admin/src/pages/UsersPage.tsx`

```typescript
const mappedUsers = data.users.map(u => {
  const bonusBalance = u.bonusBalance ?? u.bonusPoints ?? 0;
  console.log(`👤 ${u.name}: бонусов ${bonusBalance}`);
  return { ...u, bonusBalance };
});
```

Теперь в консоли видно сколько бонусов у каждого пользователя:
```
👤 John Doe: бонусов 2500
👤 Jane Smith: бонусов 5200
👤 User 3: бонусов 7842
```

### 3. Поддержка обратной совместимости

Код поддерживает оба формата API:
- `bonusBalance` (новый формат)
- `bonusPoints` (старый формат, fallback)

```typescript
const bonusBalance = u.bonusBalance ?? u.bonusPoints ?? 0;
```

## Дополнительно

### Тестовые данные

API теперь генерирует 50 пользователей с реалистичными значениями:
- Бонусы: 0-10000 ₸
- Потрачено: 0-100000 ₸
- Разные уровни: Новичок, Любитель, Эксперт, VIP

### Performance

Загрузка остается быстрой (<1 сек) благодаря пагинации:
- Загружается 20 пользователей за раз
- Данные о бонусах приходят сразу из API users
- Нет дополнительных запросов к API bonus

## Проверка

Для проверки откройте консоль браузера и найдите строки:
```
👤 User Name: бонусов 2500
```

Если видите `бонусов 0` для всех - проверьте что mock API возвращает `bonusBalance` > 0.
